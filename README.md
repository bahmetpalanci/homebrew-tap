# Homebrew Tap

Homebrew formulae for tools by [@bahmetpalanci](https://github.com/bahmetpalanci).

## Install

```bash
brew tap bahmetpalanci/tap
```

## Available Formulae

| Formula | Description | Install |
|---------|-------------|--------|
| [mic-mute](https://github.com/bahmetpalanci/mic-mute) | One-click microphone mute/unmute for macOS menu bar | `brew install mic-mute` |
| [teams-volume](https://github.com/bahmetpalanci/teams-volume) | Per-app volume control for Microsoft Teams on macOS | `brew install teams-volume` |
